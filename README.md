## รายละเอียดทางเทคนิค

- **โลโก** วาดใหม่เป็น inline SVG (`<symbol id="mark">`) จากไฟล์ภาพต้นฉบับ
  ถ้ามีไฟล์เวกเตอร์จริง สลับมาใช้ได้ทันทีที่จุดนี้
- **การตัดบรรทัดภาษาไทย** ไทยไม่มีช่องว่างระหว่างคำ ทำให้วรรคยาวกลายเป็น token
  เดียวที่ดัน grid track กว้างเกินกรอบ แก้ด้วย `min-width: 0` บน grid item
  และ `overflow-wrap: break-word` บนหัวเรื่องกับเนื้อหา
- **Responsive** 3 breakpoint (1000 / 900 / 640px) เมนู hamburger ต่ำกว่า 900px
- **A11y** skip link, `prefers-reduced-motion`, focus-visible, ARIA บนเมนูและ toast,
  landmark ครบ, ตัวนับหยุดนิ่งเมื่อผู้ใช้ปิดแอนิเมชัน
- **ตรวจแล้ว** ไม่มี horizontal overflow ที่ 375 / 768 / 901 / 1280px

## Deploy

**Vercel** — push/อัปโหลดขึ้น GitHub แล้ว Import repo → Framework Preset: **Other** → Deploy
(ปล่อย Build Command และ Output Directory ว่าง เพราะเป็น static)

**GitHub Pages** — Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save
